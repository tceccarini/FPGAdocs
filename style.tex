    captionpos=t, title={\makebox[\linewidth][r]{\scriptsize\bfseries On the board}}}}{}

% ------------------------------------------------------------
% Category-colored inline code: same idea as |code| above, but tinted by
% semantic category to make scanning easier. Each style below inherits
% from githubcppinline (language, wrapping, ...) and overrides every
% text-bearing key -- basicstyle, identifierstyle, keywordstyle,
% commentstyle, stringstyle -- to the category color; leaving any one of
% them unset falls back to githubcpp's black identifierstyle, silently
% recoloring plain words back to black.
%
% Unlike |code|, these can't be lstMakeShortInline delimiters (one desired
% pair, catFilesystem's two shades, would need two different delimiter
% characters that still had to be remembered) -- they're plain macros
% wrapping \lstinline[style=...]{...} instead. \lstinline's brace form
% re-tokenizes its argument in verbatim mode same as its short-inline form,
% so it survives being passed through a \newcommand argument.
%
%   \extpath{...}   filesystem path outside the repository
%   \repopath{...}  filesystem path inside the repository
%   \ccode{...}     C/C++ code (functions, classes, members, macros)
%   \cmd{...}       a command/executable found on PATH
%   \cmdpath{...}   a command/executable NOT on PATH (run via explicit path)
%   \hw{...}        hardware/FPGA (peripherals, Qsys signals, registers, Kconfig)
%   \sysid{...}     system-level identifier (env vars, users, groups)
