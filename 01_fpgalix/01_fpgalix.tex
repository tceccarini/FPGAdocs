\chapter{\sysname{FPGAlix}}
\label{chap:fpgalix-intro}

\sysname{FPGAlix} interfaces an \term{OV7670} camera module with a \term{Terasic DE1-SoC} developer board through custom \term{FPGA} hardware using \term{DMA} (\term{mSGDMA}), so that transferring the video stream into memory requires no \term{CPU} involvement in the handling of individual bytes. Unlike its bare-metal successor, \sysname{FPGAsteel}, \sysname{FPGAlix} runs a full embedded \term{Linux} system (\term{Buildroot}) on the \term{HPS}: a \term{V4L2} kernel driver exposes the camera as a standard |/dev/video0| device, and a user space pipeline, |vision_core|, filters the stream and serves it out over \term{RTSP}. It also documents, step by step, the full toolchain and development environment needed to build and run it.

\section{Quick Start}
\label{sec:fpgalix-quick-start}

The prebuilt SD card image already contains the bootloader, kernel, root filesystem and \term{FPGA} bitstream, letting the \term{DE1-SoC} boot straight into a running system, without building anything from source.

\begin{warningbox}
\textbf{Hardware bug:} do not leave the camera in \term{RESET} or \term{POWER-DOWN} for extended periods.\footnotemark
\end{warningbox}
\footnotetext{See Appendix~\ref{app:camera-adapter-board} -- Camera Adapter Board: full analysis of the camera \term{RESET}/\term{POWER-DOWN} hardware bug and the two permanent fixes [ADAPTER-WARN].}

\subsection{Hardware needed}

\begin{itemize}
    \item A \term{Terasic DE1-SoC} developer board.
    \item An \term{OV7670} camera module.
    \item The custom camera adapter (transmitter and receiver boards, connected by a ribbon cable), wiring the camera to the \term{DE1-SoC}'s \term{GPIO\_0} header.
    \item A microSD card, at least 8 GB.
    \item An \term{Ethernet} cable, for network access.
    \item A PC on the same network, to reach the board over \term{SSH} and view the video stream.
    \item A micro-\term{USB} cable, for the board's serial console. Optional: only needed to log in as root directly, or for troubleshooting.
    \item A power supply for the board.
\end{itemize}

\subsection{Preparing the SD card}

\begin{enumerate}
    \item Download the SD card image from |download.md| and extract it.
    \item Write the extracted image to the microSD card (at least 8 GB) with any disk-imaging tool, e.g. |dd| on \term{Linux} or \term{balenaEtcher} on Windows/Mac.
    \item Insert the card into the \term{DE1-SoC}.
\end{enumerate}

\subsection{Board configuration}

Before powering on, set the \term{DE1-SoC}'s \term{SW10} DIP switch, on the underside of the board, so that switches 1 through 5 are ON (\term{SW10} uses negative logic: ON means logic 0). This lets the \term{HPS} configure the \term{FPGA} fabric from the SD card at boot.\footnote{TODO: footnote text was lost when the source was copy-pasted -- please supply it.}

\subsection{Booting and logging in}

Connect the \term{Ethernet} cable, insert the SD card, and power on the board. The board's IP address is shown automatically, a few seconds later, on the 7-segment displays, cycled one octet at a time by |hexip_daemon|.\footnote{TODO: footnote text was lost when the source was copy-pasted -- please supply it.}

Two ways to log in, default password |1q2w3e4r| for both accounts:

\begin{itemize}
    \item over \term{SSH}, once the IP is known, as |wheel|, then |su| for anything that needs root (loading |camera_driver_2|, accessing hardware registers directly):

\begin{shellcode}
ssh wheel@<board-ip>
\end{shellcode}

    \item over the serial console (115200 baud, 8N1, e.g. |picocom|), directly as |root|; no network needed for this path.\footnote{TODO: footnote text was lost when the source was copy-pasted -- please supply it.}
\end{itemize}

\subsection{Running the software}

|hexip_daemon|\footnote{TODO: footnote text was lost when the source was copy-pasted -- please supply it.} is already running once the board boots; no action needed. The prebuilt SD card image also already contains |camera_driver_2| and |vision_core|, built and placed in |wheel|'s own home directory (|/home/wheel/camera_driver_2/|, |/home/wheel/vision_core/|); no building or |scp|-ing is needed here. Building from source and deploying over |scp|, covered in full in Chapter~\ref{chap:fpgalix-camera-driver-2}\footnote{TODO: footnote text was lost when the source was copy-pasted -- please supply it.} and Chapter~\ref{chap:fpgalix-vision-core}\footnote{TODO: footnote text was lost when the source was copy-pasted -- please supply it.}, only matters after changing their source.

Log in as |wheel| (or |root| from the serial console, cd-ing to |/home/wheel| first), then bring the camera up and load the driver:\footnote{TODO: footnote text was lost when the source was copy-pasted -- please supply it.}

\begin{shellcode}
cd camera_driver_2
su                              # Not need if already logged in as root.
./resetCtrl.sh                  # option 2, deassert reset
./ov7670_ctrlif_set.sh          # select Bayer mode (1)
./ov7670_dataif_ctrl.sh         # option 1, enable frame acquisition
insmod fpgalix_camera.ko        # load camera driver module
\end{shellcode}

Then run |vision_core|,\footnote{TODO: footnote text was lost when the source was copy-pasted -- please supply it.} still as |root|, from the sibling directory:

\begin{shellcode}
cd ../vision_core
./vision_core
\end{shellcode}

It prompts interactively; every prompt accepts its default by pressing Enter, except the source, which must be set explicitly to |ov7670|:

\begin{shellcode}
Source [webcam/ov7670, default: webcam]: ov7670
Encoding [mjpeg/h264/raw, default: mjpeg]:
\end{shellcode}

|ov7670| is mandatory on the board, the |webcam| source being only for the native \term{Intel} (|make intel|) build; |MJPEG|, left at its default by pressing Enter, is what this project recommends for full-color output here since the \term{HPS} having no hardware video encoder.\footnote{TODO: footnote text was lost when the source was copy-pasted -- please supply it.}

Once running, view the stream on a PC:

\begin{shellcode}
ffplay -fflags nobuffer -flags low_delay -framedrop rtsp://<board-ip>:8554/stream
\end{shellcode}

\section{Repository layout}

\begin{itemize}
    \item |hw/|: \term{FPGA} hardware project (\term{Quartus Prime} + \term{Platform Designer}).
    \begin{itemize}
        \item |camera_adapter/|: custom \term{PCB} bridging the \term{OV7670} to the \term{DE1-SoC}'s \term{GPIO\_0} header.
        \item |my_vhdl/|: custom \term{Platform Designer} \term{VHDL} components written for this project.
        \item |quartus/|: \term{Quartus} project, |soc_system.qsys|, top-level \term{VHDL}, pin assignments.
    \end{itemize}
    \item |sw/|: application software running on the board's embedded \term{Linux} (\term{C/C++}), one folder per component.
    \begin{itemize}
        \item |camera_driver_2/|: \term{V4L2} kernel driver for the \term{OV7670}.
        \item |hexip_daemon/|: displays the board's IP on the 7-segment displays.
        \item |vision_core/|: captures, filters and streams the camera feed over \term{RTSP}.
    \end{itemize}
    \item |repos/|: git submodules (\term{U-Boot}, \term{Linux} kernel, \term{Buildroot}, \term{GHRD}, |sopc2dts|, \term{Altera} \term{FPGA} top-level files).
    \item |sdcard/|: SD card boot partition contents and root filesystem overlay, used to assemble the flashable image.
    \item |docs/|: reference manuals and this project's own documentation.
    \begin{itemize}
        \item |Altera/|: \term{Intel}/\term{Altera} manuals (\term{Avalon} interface specs, Embedded Peripherals IP User Guide, Cyclone V HPS Technical Reference Manual).
        \item |FPGAlix/|: this project's own numbered documentation (this file included).
        \item |Misc/|: miscellaneous reference material (bootloader generation flow).
        \item |OV7670_CameraModule/|: \term{OV7670} datasheet, implementation guide, and camera module schematic.
        \item |Terasic_DE1-SoC/|: \term{DE1-SoC} schematic, \term{GHRD} archive, and \term{Terasic}'s own user manuals.
    \end{itemize}
    \item |WARNING.md|: camera hardware bug note (symlink to |hw/camera_adapter/WARNING.md|).
    \item |LICENSE|: MIT
\end{itemize}
