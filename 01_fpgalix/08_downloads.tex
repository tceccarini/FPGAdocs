\chapter{Downloads}
\label{chap:fpgalix-downloads}

\term{Quartus Prime} 22.1, the \term{ARM GNU} toolchain (|arm-gnu-toolchain-12.3.rel1-x86_64-arm-none-linux-gnueabihf|), and the \term{Ubuntu 22.04 LTS} image, used to install the development environment on the host \term{PC},\footnote{See Chapter~\ref{chap:fpgalix-devenv}} are all available from their respective official sites.

A shared folder, linked from the \texttt{FPGAdocs} repository's \texttt{README}\footnote{\texttt{FPGAdocs} \texttt{README} --- \url{https://github.com/tceccarini/FPGAdocs/blob/main/README.md}} (publicly accessible, no account required), mirrors everything needed to follow this tutorial without hunting down each piece separately:

\begin{itemize}
    \item the compiled thesis \term{PDF};
    \item the camera adapter board documentation (schematics, bill of materials, \term{PCB} layouts);
    \item third-party reference documentation (datasheets and manuals cited throughout this work);
    \item installers for the software listed above;
    \item a prebuilt \term{SD} card image for the \term{DE1-SoC} board itself, bootloader, kernel, root filesystem and \term{FPGA} bitstream already built, letting the board boot without going through the full build process (see the project's Quick Start\footnote{See Section~\ref{sec:fpgalix-quick-start}}).
\end{itemize}
